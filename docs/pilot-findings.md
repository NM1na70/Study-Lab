# Pilot Findings And Expansion Decisions

The initial six-lesson checkpoint added English spelling/reading and Cybersecurity DNS/authentication before the remaining fourteen lessons were authored

The pilot exercised typed spelling, fixed choices, exact sets and short self-reviewed writing — deterministic domain completion, schema/source validation and independent evidence extraction passed at that checkpoint

The original report builder assumed HTTP fields — expansion therefore introduced content-defined report sections with the original HTTP layout retained, enabling the English handover and combined cybersecurity case without forcing unrelated fields

Multiple lessons per course exposed the old one-lesson review selection assumption — course-based Mistake Review now tracks a single active lesson/task across all matching lessons, with persistent Remove/Undo retained

Review recall needed separate history to avoid turning repeated practice into assessed attempts — dedicated schedules/sessions/results now preserve original answers and completion, tested with controlled clocks and stale revisions

The expanded original browser journey exceeded its existing per-test budget because it attempted every lesson in one test — the original two-lesson journey remains, and each new lesson now has its own full-control desktop/mobile test with the same assertions and timeout

Native select labels initially included their option text in the accessible name — explicit labels fixed the filter interaction, and the targeted filter/accessibility check passes

AI owner state deliberately lives only in memory — the browser test now performs an actual page reload when checking that owner access locks again, rather than treating a hash route change as a reload

Remaining limitations: small synthetic record sets teach reproducible investigation methods rather than production-scale triage, durations are estimates including teaching/reflection, and mock AI evaluations verify safety/transport behavior rather than actual model judgement
